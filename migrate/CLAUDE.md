# migrate/
`backfill-nw.js` — **One-shot** (`npm run backfill:nw > backfill-nw.sql`): reconstructs pre-cron monthly net worth into `nw_snapshots`. Loads the `dev:pull` dump into an in-memory `node:sqlite`, reuses the app's own `deltas`/`shapeAccounts`/`netWorthTotals` so a backfilled figure matches a live one, and values each month with historical prices + USD/PHP from **Yahoo Finance's v8 chart endpoint** (keyless, browser UA; covers the LSE UCITS ETFs via `.L` and USD/PHP via `USDPHP=X`, returns the quote currency). `fetchDailySeries` is the swap point if Yahoo ever refuses; **IBKR can't** (Flex has no date param, no PHP FX) and **Stooq's keyless CSV is JS-PoW-walled**. `SYMBOL_MAP` maps IBKR ticker→Yahoo where they differ (US names identical). A series that fails is non-fatal: months needing it are **skipped and reported**, never half-valued (`ON CONFLICT DO NOTHING`, so real snapshots are never clobbered). `--self-test` checks the valuation + as-of lookup with no DB/network.
