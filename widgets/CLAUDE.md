# widgets/
`memento-mori.js` — **The iOS Scriptable widgets** (recent / balances / networth / segments, picked by the widget Parameter). ONE script, ONE GET: `getWidget` (api.js) runs the balance fold once, hands it to `getDashboard` (its optional 3rd arg `pre`) and trims the result to what the four draw; the phone reuses a payload <15 min old (`FRESH_MS`), so four widgets refreshing together cost one request; the balance widget's accounts are `meta.widget_accounts` (JSON list, ≤3), written by `setWidgetAccounts` from the Admin screen's picker card and echoed in `getBootstrap.widgetAccounts`. Auth = `/login` once in the app, only the `mm_auth` cookie kept in the Keychain. Colours are `app.css`'s tokens — change them together. It runs only on a phone, so `test.js` just compiles it and checks every `action=` it calls is a read route. Install steps live in README.
